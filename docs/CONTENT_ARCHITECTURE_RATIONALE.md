# 沿着内容走一遍：内容与建筑的对应说明

本轮为未发布预览，基于已上线的 f2c2960。26 个入口逐一核实；RSS、Vaultwarden、知虾标书仅能看到登录前界面，其主体保留。其余 22 座功能馆重新组织空间，蝶阙仅增加周边观看序列，三座数学馆保留。

## 共同的空间语言

本轮重设的功能馆保留地面直达和至少 3.6 m 的中间通路；原数学馆通路保持。意义主要来自空间的顺序、相望、遮挡、回返与材料层次，而非图标和大段说明牌。石、木、氧化铜维持共同家族；普通铜金细节降饱和、增粗糙度。地面略提亮偏灰绿，路网减弱对比，蝶阙保持更明确的浅底层次。

构件按钮用于阅读空间状态，不调用链接平台的真实生成、照护、监测或业务功能。所有设计对应都是建筑诠释；公开界面的存在并不证明后台能力、临床效果、史实或科学推想已被独立验证。

## 阅读与实现边界

- 仅读取公开呈现的页面与必要子页，没有登录、提交表单、录音、拍照、创建项目或触发照护操作
- 文学页面按其自述阅读，没有把潜在原始聊天档案当作已访问或已核实资料
- 家庭界面的样例信息不作为用户事实，也不复制到建筑、截图说明或新报告中
- 原有生物模型、来源署名、音乐、导航和机械铰链系统保持；新增建筑不是结构工程或医疗功能认证
- 最终通行、构件、相机与资源验证见本轮测试结果；未获新发布批准，不推送或部署
