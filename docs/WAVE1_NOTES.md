## 移动端与资源预算

- 台阶、路面、入口框、栏柱、卵石使用批次 InstancedMesh；Tree/StoneLantern/SteppingStone 的 GLB 子网格按 geometry/material 合批实例化。
- 桌面 DPR 上限 1.5；移动 1.15，持续慢帧进一步降为 1。移动关闭 bloom 和实时阴影（保留 ±40m/1024 阴影配置），使用假阴影及平面水材质；远山减半，星/粒子/云减少。
- 地标与数学三岛在远处切为不受实时光照的简化体；桌面距离 210m、移动 115m，±12m 滞回避免闪切。持续慢帧仍会触发原有自动降级机制。
- index.html 从 96,431 增至 106,528 字节；gzip 从 33,940 增至 37,422 字节。没有新增网络依赖、模型、贴图或音频资源。

## 可复现验证

先在仓库运行 `python3 -m http.server 8874 --bind 127.0.0.1`，另一终端：

```sh
PLAYWRIGHT_PATH=/path/to/installed/playwright node docs/wave1-check.cjs http://127.0.0.1:8874
```

## 下一波建议

1. 先确认 A4 使用“离地高度”作为正式验收定义，消除与高台起伏的矛盾。
2. 真机测中端 Android/iOS 的 GPU、长时漫游与热降频；桌面多种显卡验证大面积阴影成本。
3. 在允许编辑模型后，为横向很宽的雕塑重做承台/悬挑支承，细化可进入的建筑门洞及主体碰撞。当前提供可达参道、台地和外部观赏，并未制作楼内空间。
4. 可继续精修远距 LOD 的轮廓辨识度与转场；本轮采用简单几何剪影以控制开销。
