## 移动端与资源预算

- 台阶、路面、入口框、栏柱、卵石使用批次 InstancedMesh；Tree/StoneLantern/SteppingStone 的 GLB 子网格按 geometry/material 合批实例化。
- 桌面 DPR 上限 1.5；移动 1.15，持续慢帧进一步降为 1。移动关闭 bloom 和实时阴影（保留 ±40m/1024 阴影配置），使用假阴影及平面水材质；远山减半，星/粒子/云减少。
- 地标与数学三岛在远处切为不受实时光照的简化体；桌面距离 210m、移动 115m，±12m 滞回避免闪切。持续慢帧仍会触发原有自动降级机制。
- index.html 从 96,431 增至 106,528 字节；gzip 从 33,940 增至 37,422 字节。没有新增网络依赖、模型、贴图或音频资源。

2. 真机测中端 Android/iOS 的 GPU、长时漫游与热降频；桌面多种显卡验证大面积阴影成本。

4. 可继续精修远距 LOD 的轮廓辨识度与转场；本轮采用简单几何剪影以控制开销。

## Wave 1.5 · 治过曝、退后观赏、建筑夜色化

本波任务书为 `WAVE1_5_POLISH.md`，在 Wave 1 提交 `2b62069` 上实施。仍使用现有本地 Three.js r128、34 个 GLB 和音频，未编辑模型二进制。下列条目更新了上文 Wave 1 的灯光、仰拍、标签和主体碰撞说明。

### 参数与实现

| 系统 | Wave 1.5 最终实现 |
| --- | --- |
| HDR / bloom | 保留线性 HDR 中间缓冲与唯一末级 ACES，exposure=1.05；bloom threshold=2.8、strength=0.18、radius=0.35；移动仍关闭 bloom。提灯增加一枚 7cm 宽的小灯芯，HDR RGB=(6,3.5,1.2)，灯室与原有灯肋保持可见 |
| 尺度补偿 | `placeMonument` 为每个 wrap 克隆并复用材质；emissive intensity=`min(0.3, original*0.36/sqrt(max(1,scale)))`，发光件底色乘 0.28；访问点亮仅乘 1.08，不再恢复原来的 2.3–3.45 强度 |
| 夜色与梯度 | 非发光主体线性底色乘 0.34，保留色相；夜间 hemi=0.48、moon=1.05，保留冷暖方向光差。2.4m 石灯笼弱光室=0.24、四面小灯芯=2.9；按相机世界距离以 `0.18+0.82*exp(-d/38)` 衰减，桥栏灯同样克制；人物仍是最近的暖光锚点 |
| 通用 dressing | 从实际三角面归并共面多边形，在世界米制中贴合斜面；沿真实多边形裁切线脚，不用笼罩主体的方盒外壳。按实际落地支点生成 0.38m 深色台基（开放拱洞不跨接整块底板）、0.42m 下缘/压顶、1–3 道 0.18m 腰线；大面按 ≤3.5m 模数配置 0.16m 稀疏壁柱。每主体使用两个 InstancedMesh，共享 box geometry 和两种深色材质；GLB 回退和数学三岛共用此流程 |
| 最终 AABB | 主体与 dressing 的最终世界包围盒参与碰撞。**r128 的 Box3.setFromObject 不处理 instanceMatrix**，故显式变换并合并每个实例的 geometry boundingBox；回归再从实例顶点独立重测，防止装饰层漏入碰撞盒 |
| 仰拍与取景 | 最小水平距离 k=0.5（桌面）/0.62（竖屏）乘最终 bboxHeight；另按实际 FOV/aspect 与八个包围盒角点拟合完整轮廓，实际距离通常更大。视线目标朝 42% 高度，但终点停在可见 AABB 表面外 1.3m，避免以建筑内部中心作为“无遮挡”判据 |
| 观赏选址 | 优先参道中轴，遇遮挡才沿周围候选角度寻找无遮挡机位；靠近入口和朝向实墙的参道会自动退后；用实际模型射线识别开放拱洞，保留其近景参道仪式感。岸边相机臂被身后建筑阻挡时，空闲视角转向前方远景主体，避免缩进人物背部。相机沿目标→相机射线收起，必要时从膨胀 AABB 侧面推出，安全间距 1m；相机保持当地表面以上 2.1m |
| 手动视角 | 指针/滑屏、viewpad 键盘与滚轮输入优先；操作结束后 2.5s 内 framing=0；之后平滑恢复。俯仰输入继续改变实际注视高度，pitch 范围保持 −0.5…0.62 |
| LOD / 标签 | 远景为无实时光照的深色主体剪影，加一枚小暖色顶点；借景山体先于主体绘制且不写深度，避免竖屏后退机位被布景山体挡住；装饰随主体 LOD 隐藏；正在主动取景的数学岛主体保留完整模型。名称移至相机侧顶部边缘以上 5m（含数学三岛），beacon 横向错开 2m 且缩为 1.5 倍；保留深度遮挡，并按屏幕范围避开顶栏、画面边缘和其他名称，当前入口优先 |
