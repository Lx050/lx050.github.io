# 海陆空探索世界 · 首版

本版从已发布 `7bf71adc9fb3e80cc86ad01fbe9e207f26aa37c6` 演进。默认入口为新的探索世界；`?courtyard=1` 保留原庭院、数学岛与原卷中漫游，不改写原内容。

## 空间与身份

- 世界边界为 2.8 × 2.4 km，两个可驾驶大陆、五座服务岛、起航岛、蝴蝶岛与三座高空岛。
- 26 个来源入口保留稳定索引、URL、题名、匿名化文本、完整本地阅读文件、实际建筑网格和构件。原建筑根组直接移入新场景，不复制 26 份旧世界。
- 最近建筑间距 200 m；地面建筑有 50 m 平坦留白，蝴蝶为 100 m。
- 地形使用 96 个小网格块，海面只有一个低细分面。近景为原建筑，远景为路标轮廓；额外细节、机制更新与碰撞查询均有距离范围。固定资源池不会因旅行不断增加。
- 不宣称完全动态流式加载。旧兼容场景及全部原建筑依然在内存中，减少的是新地形开销、可见绘制与远处更新。

## 行走与交通

- 首次进入位于墨息建筑入口，左上持续显示世界地图；12 秒非阻挡提示说明自由传送。R 安全返回起航岛。
- WASD / 方向键或摇杆移动，拖动环顾；M 世界地图，R 安全返回。
- V 使用陆行车或下车：可见车身、惯性和转向，不能驶入海中或穿墙。
- B 在码头登船或靠岸下船：独立可见帆舟，只能航行于允许的水域，不能在海中切换步行。
- F 展开滑翔翼或安全落地：空格上升，Q / Ctrl 下降；触屏有独立升降按钮。起飞、飞行、降落都有完整翼展净空检查，不能直接穿过建筑或天空岛。
- 地图中的全部 26 建筑和 9 码头从一开始可传送，不设进度门槛。传送前验证已加载的真实地面和人物净空，并清空运动输入、惯性、关卡会话和相机过渡。
- 场景不依赖异步按地点加载，因此无等待目标资源的竞态；原来可选的本地模型仍有原有降级路径。

## 关卡范围

本版是一个共同的轻量空间探索框架，不是 26 个独立定制的大型谜题。

每座建筑有与原构件/公开内容对应的三步动作，分布在可实际步行到达的观察点，按次序操作后返回入口完成。操作必须在对应点附近，远处点击不能推进。各建筑的动作、原始内容和路线次序不同；没有改写故事、没有要求读完全文、没有杜撰登录后账户功能。RSS、Vaultwarden、标书仍只展示公开入口的边界说明。

可以随时退出，重访，独立阅读全文或访问原站。只把关卡完成记录保存在当前浏览器；私密模式/损坏存储不会阻断游玩。

## 验证

    node docs/exploration-release-check.cjs

或分别运行：

    node docs/exploration-geography-check.cjs
    node docs/exploration-levels-check.cjs
    node docs/exploration-transport-check.cjs
    node docs/exploration-world-check.cjs

`exploration-world-check.cjs` 执行真实生产 Three.js 构建器、原步行器、26 个关卡动作、连续航线和交通切换，DOM/renderer 是惰性替身。独立审查另外比较原 3902 个建筑网格、射线测量地形/道路/蝴蝶地面，并连续步行各关卡。

这些是源码、实际几何与 CPU 运动证据，不是 WebGL、FPS、Safari、手机实机或屏幕触控证据。云端浏览器和执行器的本地服务器不互通；执行器 Chromium 启动也被 socket 权限阻断。离线 Blender 图仅为生产几何审图，着色器、纹理文字、光照与最终浏览器画面存在差异。

历史庭院/道路的固定布局门禁继续保留在原提交，不将它们放宽来适应新世界坐标。新首版使用上列专门检查；原内容文件另有字节级保留比较。
