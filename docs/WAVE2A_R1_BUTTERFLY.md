## 必须修掉的四个具体问题（现状证据）
1. **主翼是 4 块带厚度的矩形画板/瓷砖**：GLB 的 Wing/Back 是薄片 Box，放大后成约 1m 厚、硬直角、带深色边框的板子，围着一根粗黑身体柱 + 一个金色低模多面体，像墙上挂的 4 块显示器。**近景必须替换为程序化蝶翼**（你在远景剪影里已经用 `THREE.ShapeGeometry` 画过蝶翼轮廓——把同样的蝶形做成近景主翼）。
2. **万彩是放射烟花/光纤星轨**：现在颜色从一点向外放射成光束 + 密集亮点，像屏幕放烟花。要改成**翅脉网络 + 掐丝珐琅/墨染绢色**语言（见 §2）。
3. **蝴蝶贴在一栋办公板楼墙上**：留白画壁被做成一整面 40m 大板楼、蝶贴在墙面。要做成**独立、薄、空灵的写意展亭**（见 §3）。
4. **远景剪影是十字/风车/X，一眼不是蝶**：剪影必须是四翅展开的经典蝶形（复用 §1 的蝶翼轮廓）。

## 1. 程序化蝶翼几何（替换 GLB 矩形翼）
- 隐藏/移除 GLB 的 8 片矩形翼（`WingLL/WingLR/WingUL/WingUR` + `BackLL/BackLR/BackUL/BackUR`）。为每侧的**上翅、下翅**各用 `THREE.Shape`（贝塞尔/样条）画一片经典蝶翼：
  - 上翅大、前缘弧挺、外缘圆阔且带轻微波浪、近翅根收窄；下翅小而圆润、后缘可带小小的尾突（凤蝶意）；左右严格镜像。
  - **Shape 坐标原点放在翅根**（贴身体侧），使铰链旋转天然绕翅根；翼面极薄——优先 `ShapeGeometry`（`side:DoubleSide`），若需厚度用 `ExtrudeGeometry` 且放大到 50m 后整翼视觉厚度 ≤0.2m，**边缘不得出现厚框**。
  - 给翼面轻微"瓦状"弧（沿翼展/翼弦的顶点微位移，蝶翼静息时的微翘），不要平板一块。
- 铰链沿用你实测的翅根 pivot（±0.045,1.145,.24 一带，以新几何重测），左右绕正确轴呼吸；保留 16s 闲/4.8s 近、≤0.42rad，可让上/下翅有极细微相位差，更生物感。
- 翼材质双面、绢质感（常态近实、微透），薄翼可不投影以免脏影。
- 远景 LOD 剪影**复用同一蝶翼 Shape**（四翅 + 细身 + 一点暖光，定格微展翅），替换当前六块剪影板。

## 2. 翅脉与万彩：掐丝珐琅 / 墨染绢色（删除烟花语言）
- **翅脉网络**：在翼面 UV/局部坐标里程序化生成**分叉树枝状脉络**——一条主脉自翅根向外缘，分 2–3 级侧脉，外缘有细横脉相连成网。脉络是极细的"掐丝"暗金/亮金线；脉间是一块块细胞状填彩区。
- **显色方式**：uReveal 上升时，颜色**沿脉络自翅根向外缘、如墨入绢/珐琅逐格填彩**般浸染推进，边缘羽化柔和；**禁止**从单点放射的光束、星轨、光纤、密集爆炸亮点。
- **配色分区、克制**：每片翅以 1–2 色为主调（例：左上黛青+石绿、右上朱砂+藤黄、下翅紫+青，左右对称或呼应），靠 uTime 极缓慢呼吸/流动；**不要一翅塞满五色、不要彩虹渐变**。鳞粉表现为绒面细微虹彩（掠射角微亮），不是亮粒子。
- 金线脉络在夜里极细微发光（配合 bloom threshold 2.8，只许细线发光，近白像素继续≈0）；常态素绢暖灰低饱和微透，峰值雅致、艳而不俗。保留昼夜（夜显昼淡）、visited 余色、离开褪色。
- 色板可继续用 `#365b65 #a65342 #b99a52 #558575 #78617e`，但按区分色、降低同时出现的饱和度总量。

## 3. 蝶身与独立展亭
- **蝶身**：删掉粗黑柱与金色大多面体。程序化纤细蝶身——小梭形胸、向后渐细的**分节腹部**（数节、深色带极细金环节线）、小头小球；两根**细长、末端微弯的触角**（细 Tube/锥沿曲线）。尺度与巨翼协调（纤细则可）。"一点灯"只在头顶/胸前留极小暖光。
- **展亭**：把 Panel/FrameTop 转化为一面**独立、薄、边缘精致的素屏/碑**（薄、宽高恰好框住蝶、细边框、素绢或青石质感，**不要窗格/壁柱/楼体**）；蝶停在屏**前方并与屏拉开间距**——可凭空轻悬，或停在一枝自台座升起的**纤细枯枝/细柱**上（写意"枝头未上色之蝶"）。台座沿用克制浅台。
- 参道中轴仰拍构图须成立：素屏为背景、巨蝶居中、夜空/月在上，空灵而宏伟；确保 `monumentView` 中轴机位能取到"整蝶+屏"且无遮挡（你之前为蝴蝶加密到 145 step/π72 的取景搜索保留并按新轮廓复核）。
