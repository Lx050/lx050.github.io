# 生物金凤蝶接入（2026-10-08）

替换《素墨长卷》内部终点的雕塑蝴蝶，外部海上蝶阙建筑保持原样。采用独立 Papilio machaon 网页资产；原 MyriadButterfly.glb 与其他源资产保留。

展示为约 8m 翼展的观览放大模型，位于 (0, 8.7, -151)，沿用长卷观察台和步道。原始建模按米制约 6.8cm；本次放大是展示选择，不声称真实生物尺寸。保留拖动、行走、E 进出与归途。内部到达仰角和窄屏镜头针对新的展示调整，未恢复庭院建筑自动夺镜。

模型仅进入内部时懒加载。桌面普通质量使用 4K / 9,193,180 bytes；触摸、窄屏或低质量使用 2K / 5,759,672 bytes。两版均 111,776 三角形，不加载 102MB Blender 高模。成功模板仅在 CPU 缓存；每次进入克隆几何、材质与纹理并登记释放，离场后迟到的请求不能挂载到旧实例，失败请求可重试。

保留照片色彩与薄翼、复眼、触角、口器和六足。网页鳞片为法线近似；没有恢复雕塑珐琅材质、机械扇翅或声称自然飞行仿真。未增加建筑重建、碰撞/重力系统。

纹样为 Didier Descouens / Muséum de Toulouse 博物馆照片的改编，CC BY-SA 4.0。逐张来源、作者、许可和修改说明在 `assets/models/PapilioMachaon-ATTRIBUTION.md`，内部 HUD 提供署名链接。解剖与微结构仍是照片参考的艺术重建，未据显微测量复原。

本地验证使用已安装 Chrome / CDP / SwiftShader，以现有有限步进句柄覆盖 E 进入与返回、资源释放、重复进入和延迟加载快速重入；桌面与模拟 390×844 布局都检查 JS/网络错误。模拟视口不作为手机真机性能测试。实际测试结果与上线确认由交付记录提供。
