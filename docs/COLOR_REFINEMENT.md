# 黄昏配色修订 / 未发布

本次不是重新建模。内容驱动建筑、导航、机械铰链、生物蝴蝶内景保持。

## 从实际画面识别的缺口

普通建筑的细金边已比较克制，屋面也已有灰绿色；无需对全场再次统一降饱和。仍需解决的是黄昏棕灰雾压暗地表、浅路过于抢眼、蝶翼基底发暗，以及山体巨大深色轮廓与主体争夺注意力。

## 局部修订

- 地表提高至冷灰绿，并调整纹理底色；道路和边石轻微压暗
- 黄昏的环境补光和雾色偏向中性灰绿，夕阳仍保留暖色；曝光与后期色调映射不变
- 未上色的蝶翼采用暖象牙基底，翼脉为浅暖金，保持原有受接近影响的上色机制；中央轴和机械铰点仍有明暗差
- 山体使用中层天空颜色的较暗层次，降低局部对比；没有缩放、移走或重塑山体
- 维持普通馆的已收敛金属色，补齐数学亭与桥梁旧铜件的粗糙、低饱和处理；亮金仍主要用于铰点和灯光
