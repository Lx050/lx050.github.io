## 人工复核结论（证据：/tmp/wave1-qa/*.png，需重新渲染同机位对比）
- `desktop-intro` / `fallback`：开场透过 13m 鸟居远眺，纵深与尺度成立，**保留这个气质**。
- `mindcare`：深色弧形台基 + 中轴白阶 + 门框 + 对称灯笼，仪式感最好，**这是参道语言的正解**。
- 三处硬伤（本波必修）：
  - **过曝**：`distant` 建筑发光件放大后成白色光柱、上半屏爆白；`vault` 顶部死白；`court/approach/vault/mindcare` 前景石灯笼发光室爆成纯白方块，看不出灯笼形体。
  - **毛坯白盒**：放大的 GLB 是大片素白方盒墙面（`approach/foot/court`），缺少近人尺度的线脚/分色；整体偏灰白、不够"夜"。反讽的是掐断 GLB 的程序化 `fallback`（红顶/窗格/门/深色台基/分色）反而更像建筑——目标是让放大后的主体至少达到这种建筑完成度。
  - **怼墙/穿模**：`desktop-foot` 被单一素面斜面填满；`mobile-foot`（390×844）竖屏约 2/3 被一面大墙填满，完全看不到建筑轮廓与环境。

## P0-A 过曝治理（最高优先）
1. 重标定 UnrealBloom：提高 threshold、降低 strength，使**只有灯芯/月亮/星/小面积高亮泛光**，墙面、发光室、大片窗不得进 bloom。给出无大面积 clipping 的最终参数。
2. 发光件尺度补偿：所有随 `placeMonument`/台地放大的 emissive（glow）网格，亮度不得随 scale 线性变大——对放大 wrap 内 emissive 材质按缩放做衰减（如 ×(1/√s) 或更克制），石灯笼/参道灯改为"小面积高亮灯芯 + 大面积弱光室"，近景能看清灯笼轮廓。
3. 建立光的梯度：玩家提灯是最近最暖最亮；参道灯随距离逐级变暗；建筑窗光是点缀而非整片发亮。
4. **新增自动断言（写入 wave1-check.cjs）**：在固定机位（开场、court、foot、approach、distant、vault，桌面 + 390×844 移动）渲染后 readPixels，统计显示色 luminance>0.97 的近白像素占比及其最大连通块面积；桌面近白占比 ≤2%、移动 ≤4%（月亮/星/灯芯以"最大连通块小于画面 0.5%"豁免）；并断言画面平均亮度不整体泛灰（均值落在合理夜景区间，自行给出阈值并说明）。

## P0-B 相机最小观赏距离 / 不穿模（移动竖屏尤其）
1. 为每个地标主体生成世界 AABB（含 dressing 后的最终包围盒）。第三人称相机增加**相机碰撞**：若相机将落入某主体 AABB 或距其表面过近，沿"目标→相机"射线把相机推到无遮挡点（不允许进入建筑）。
2. 仰拍 framing 改为"**退后看全**"：nearest 时相机到主体中心的水平距离不得小于 `k*bboxHeight`（桌面 k≈0.5、竖屏 k≈0.62）；目标点抬向建筑上部时，距离随仰角同步拉大（楼越高越要退后），最大仰角受限，保证主体顶部/檐口能入画，绝不把相机贴在墙面上。观景点优先落在参道中轴/台地外。
3. 玩家主动拖动/滑屏视角永远优先，松手后的自动 framing 沿用现有 2.5s 不抢镜逻辑。
4. **新增自动断言**：遍历 26 个地标在桌面与 390×844 的最近观赏机位，断言(a)相机位置不在任何主体 AABB 内；(b)相机→目标视线不被主体 AABB 拦截（线段-AABB 相交测试）；(c)相机-主体水平距离 ≥ k*bboxHeight。三项全绿。

## P1-C 去白盒：程序化建筑肌理 + 夜色分色（不编辑 GLB）
实现一个**数据驱动、InstancedMesh、通用**的 monument dressing 层，在主体按 bbox 归一放置后，依据其世界尺寸自动叠加（深色/暖灰、克制、东方写意，对齐纪念碑谷式极简，**不要堆成廉价楼房或密集窗格，保留留白**）：
1. 深色台基/须弥座压底；1–3 道水平檐口/腰线（深色细盒）；按约 2.5–4m 模数的稀疏竖向壁柱或窗格（深色细框，或零星微亮窗洞）；顶部深色压顶/檐。目标是把"几十米的整片素墙"按近人模数打破，且不遮挡 GLB 的关键可辨识轮廓。
2. **夜色化**：放大 wrap 内非 emissive 主体材质整体压暗并微偏暖灰/夜青（保留各作品模型原有色相倾向），拉开受光/背光面；原则"亮的是灯与窗，不是整面墙"。程序化 fallback 主体同样处理。
3. 远景 LOD 剪影深色化、顶部一枚暖光或轮廓线，避免白色方块漂浮。
4. **自动断言**：dressing 后，对每个主体做几何统计，不存在"世界尺寸 >12m×12m 的连续单一材质平面"（大面必须被线脚/壁柱分割）；夜间 court/foot 机位主体大面积明度落入你设定的夜色区间（不过白），把阈值写进检查脚本并说明。
