# 庭中题刻、建筑动作与天气：待视觉验收预览

基线为线上提交 9badad34f769b4aa31d58224fa4430608e697fdf。此包为修复后 v2，未部署；需要 Mac WebGL 回归验收后才可发布。

## v2 动态蝶翼屋顶修复

Mac 对 v1 的复测已通过四种不同版式、接力构件连续运动/减少动态效果、月雪正文更新。新的发布阻塞是三种翼态都存在翼面下穿雪：天气只查询常规导航建筑，而蝶阙使用独立行走系统，没有进入该列表。

v2 为蝶阙添加独立的天气屋顶记录，直接使用当前机械翼面的真实网格及世界变换，不改变导航碰撞。动态投影三角形查询逐帧更新，保留翼片之间的真实空隙，不用整块包围盒代替屋顶；骨架模式是同一屋顶的视觉剖示，隐藏翼皮仍提供物理遮雪。

月雪 QA 的三项失败为幂等选择误报：前序动作已选中对应篇章，重复选择不应重绘。v2 先在同一题刻切至另一节，再验证目标章节像素变化，同时检查再次选择保持像素稳定，没有取消实际内容变化断言。

来源说明中的档案标识来自原已公开的目录，不是本轮新增私有材料读取。本轮没有改变公开原文或月雪匿名化内容。v2 仍需 Mac 实际像素/动态翼面遮雪复验，尚未发布。

## v1 修复及回归重点

Mac M5 / Metal WebGL2 对冻结 v0 的实际验收已确认：近远雪花飘落/漂移、三维斜雨、月雪屋顶挡雪、通用近景题刻可读、建筑动作不跳出界面。发现的四项阻塞缺陷已修复，其中版式、连续性、减少动态效果与月雪更新已在 Mac 实际重测通过：

- 建筑6：四种版式现在具有不同的正文、图片与分栏位置；测试比较实际绘图坐标，排除仅标题不同的假差异
- 建筑13/14/15：显式 source-note 选择真正重绘题刻；未知章节返回失败
- 建筑19：从构件当前实际位置继续，不再首帧跳回；首个1/60秒步约1.07厘米；减少动态效果下保持静态
- 月雪：复用四块既有题刻及其 CanvasTexture，在原物体上更新匿名化章节摘句；12节像素散列均不同；初始作品像素和几何不动
- QA：新增 pauseRendering / renderFrame，每次组合渲染重置帧信息；观察者放在相机后方，不再站到碑面上。题刻测试比较实际纹理变化
- 手机：320/390/760px 顶栏按钮至少44×44px，天气仍可选；建筑说明卡缩小，地图移到工具栏下

还应补测：蝶阙近景题刻、动态翼顶遮雪、远雷峰值像素，以及上述四项修复在实际场景中的结果。

## 已实现

- 建筑点击、Enter 与附近选项不再打开整屏阅读器或跳转页面。文字留在固定世界坐标的石质题刻、墙面和桌上阅读石面；主入口的原站链接隐藏。明确的无障碍文字入口和 WebGL 失败回退保留。
- 24 座通用建筑全部采用安全室内题刻；月雪保留已有一体化墙刻与花园，蝴蝶保留原观看框上的题刻。近景纹理上限18，按距离加载；不使用始终朝向相机的字牌。
- 26 座建筑共78个选项接入具体本地动作。详见 building-actions-map.json：试写与三份入格、四个实排版式、轮廓/局部遮罩、工序暂停重播、公共来源翻页、往返示意、8秒隐私片段、3分钟可暂停计时、各故事对应篇章和原机械构件。
- 登录服务只展示核实过的公开入口、身份及未读取边界；本地展陈不连接 AI、账号、订阅、健康、支付或真实消息服务，不声称业务服务已实现。
- 天气选单：晴、飘雪、细雨、风起、远雷。雪与雨为三维粒子/线段，有正常深度测试、实际屋顶遮挡和移动构件更新。雷光仅为35秒以上间隔的柔和远处线条，不闪屏、不改变曝光。减少动态效果时粒子静止且无雷光。
- 正文 JSON 与现有隐私处理未修改。

## 尚未通过且不应略过

云端仍不能创建 WebGL 场景，但 v0 已在用户 Mac 实际渲染并发现上述缺陷。v2 的 CPU/Canvas 回归不能替代同场景复验；尚不声明修复后的实际像素、真实手机/Safari 或帧率通过。上线保持暂停。

## 在可用浏览器中验收

在包根目录运行 `python3 -m http.server 8874`，打开 `http://localhost:8874/docs/world-features-qa.html`。运行交互与像素检查，并人工查看题刻和两帧雪景。不要直接双击HTML。

1. 在月雪中庭选择飘雪，观察近/远处落雪与风向；进入屋檐下检查无穿雪，再回中庭
2. 查看13、6及其他建筑的题刻：不得有弹窗或跳转，文字固定在真实物体上，有正常遮挡，移动镜头时不跟随屏幕
3. 每馆反复点击三项，比较实际物件、篇章、画布或播放/倒计时结果；尤其检查排版后框、遮罩层、RSS/Vault/标书仅入口限制
4. 重复开合蝴蝶、切天气、切建筑，确认无控制失效或异常；测试键盘/触屏和减少动态效果
5. 运行 docs/architecture-qa.html 的移动/相机测试。浏览器检查通过后，更新发布记录再沿原GitHub Pages流程发布

额外入口：docs/inscription-texture-qa.html（仅二维字体）、docs/action-canvas-qa.html（仅Canvas逻辑）、docs/next-qa.html（无障碍回归）、docs/deployment-verify.html（预览字节校验）。
