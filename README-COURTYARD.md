# Maniforld 数字庭院：内容与空间优化版

此版本在 f2c296016f413c47da684326e6e8e1313de57af4 的基础上完成内容建筑与黄昏配色优化。发布记录以 GitHub Pages 对应提交的部署结果为准。完整目录可直接运行；小体积更新包须先按包内说明应用到准确基线。

## 启动

在解压后的目录中运行：

    python3 -m http.server 8874

浏览器打开 http://localhost:8874/ 。需要支持 WebGL 的浏览器。不要直接双击 HTML 文件，否则浏览器可能拦截模型资源。

## 本次内容

- 实读 26 个目标页面及必要子页，按内容组织 22 座功能建筑的动线、材料、采光和交互
- RSS、Vault、标书仅见登录入口，保留原建筑用途，不推断账号内部功能

- 保留全部目标 URL、音乐、原 GLB、许可、地面直达和完整跑跳/碰撞控制
- `index.html` 与 `island.html` 完全相同

逐项依据见 `docs/CONTENT_ARCHITECTURE_RATIONALE.md`，结构化证据见 `docs/content-map.json`。公开演示不是医疗、工程或后台业务验证；页面自述不等于独立事实核查。

## 验证

纯源码 / 几何检查：

    node docs/architecture-static.cjs

浏览器测试和截图：

    python3 docs/preview-server.py

打开 http://localhost:8874/docs/architecture-qa.html ，分别运行桌面和窄屏测试。附加按钮检查 448 个屋顶 / 相机方向样本及真实构件按钮。此测试服务器仅监听 127.0.0.1；生成的证据写入 `qa-results/`。

交付的 JSON 结果、全部原始截图另存于验证材料包，图文报告提供建筑索引和测试结论。

## 实现与限制

本轮模块为 `assets/content-*.js`，接入原建筑和运行时模块。采用程序化几何、共享材质、重复件实例化、视锥剔除和近景细节层，未新增外部 CDN 或大体积模型依赖。

测试设备为云端 Chromium 软件渲染；没有在真实手机、Safari 或硬件 GPU 上验证帧率，不承诺 30/60 FPS。此版本为可交互艺术建筑，未验证结构承重、风荷载、液压或机械安全；既有蝶翼的运动检查不等于连续扫掠碰撞检测。
